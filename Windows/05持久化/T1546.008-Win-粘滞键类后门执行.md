# T1546.008-Win-粘滞键类后门执行

> 引入自 SigmaHQ 官方库：`rules/windows/process_creation/proc_creation_win_cmd_sticky_key_like_backdoor_execution.yml`（引入日期 2026-10-26，规则 id 与官方保持一致以便溯源）

## 描述

检测利用 Windows 辅助功能（Accessibility Features，ATT&CK T1546.008）安装后门的行为。攻击者通过注册表 Image File Execution Options（IFEO）调试器劫持，将登录界面可访问的辅助工具（`sethc.exe` 粘滞键、`utilman.exe` 轻松使用、`osk.exe` 屏幕键盘、`Magnify.exe` 放大镜、`Narrator.exe` 讲述人、`DisplaySwitch.exe` 等）劫持到恶意命令，此后在锁屏界面连按 5 次 Shift 或点击「轻松使用」即可**无需登录**拉起攻击者载荷——这是获取 SYSTEM 权限的经典持久化手法。

本规则从**行为**侧检测：当 `winlogon.exe`（登录界面进程）直接派生命令行中包含上述辅助工具名的解释器/加载器（cmd、powershell、rundll32、mshta 等）时告警。规则等级 **critical**，官方判定 falsepositives 为 Unlikely（几乎无误报）。

## 检测日志

- **Windows 安全日志**（国内默认可得）：
  - Event ID 4688：进程创建，需要启用「审核进程创建」并加入命令行。父进程对应「创建者进程名」（Creator Process Name）字段，可匹配 `\winlogon.exe`；子进程 Image 与 CommandLine 均在 4688 正文。
- **Sysmon 日志**（如已部署）：
  - Event ID 1：进程创建，`ParentImage|endswith '\winlogon.exe'` 直接匹配。

**说明**：规则使用 `ParentImage` 字段，Sysmon 下最可靠；4688 环境依赖「创建者进程名」字段（Windows 10+/Server 2016+ 默认包含），老系统需验证该字段是否落地。不依赖 Hashes/OriginalFileName 等 Sysmon 独有字段。

## 检测规则/思路

### Sigma规则

```yaml
title: Sticky Key Like Backdoor Execution
id: 2fdefcb3-dbda-401e-ae23-f0db027628bc
related:
    - id: baca5663-583c-45f9-b5dc-ea96a22ce542
      type: derived
status: test
description: Detects the usage and installation of a backdoor that uses an option to register a malicious debugger for built-in tools that are accessible in the login screen
references:
    - https://learn.microsoft.com/en-us/archive/blogs/jonathantrull/detecting-sticky-key-backdoors
author: Florian Roth (Nextron Systems), @twjackomo, Jonhnathan Ribeiro, oscd.community
date: 2018-03-15
modified: 2023-03-07
tags:
    - attack.privilege-escalation
    - attack.persistence
    - attack.t1546.008
    - car.2014-11-003
    - car.2014-11-008
logsource:
    category: process_creation
    product: windows
detection:
    selection:
        ParentImage|endswith: '\winlogon.exe'
        Image|endswith:
            - '\cmd.exe'
            - '\cscript.exe'
            - '\mshta.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\regsvr32.exe'
            - '\rundll32.exe'
            - '\wscript.exe'
            - '\wt.exe'
        CommandLine|contains:
            - 'sethc.exe'
            - 'utilman.exe'
            - 'osk.exe'
            - 'Magnify.exe'
            - 'Narrator.exe'
            - 'DisplaySwitch.exe'
    condition: selection
falsepositives:
    - Unlikely
level: critical
```

### 建议

- 条件为三段 **AND**（父进程 winlogon.exe 且子进程是解释器且命令行含辅助工具名），正常情况下 winlogon.exe 不会派生带这些参数的进程，误报极低，可直接上线。
- 该规则捕获的是**劫持生效后的执行**；安装侧（IFEO Debugger 注册表写入）需配合注册表审计（Event ID 4657 / Sysmon Event ID 13）覆盖 `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\*` 路径。
- 命中后重点排查：该机器此前是否被 RDP/暴破登录、相关注册表键值的写入时间与写入账户、后门指向的载荷路径。
